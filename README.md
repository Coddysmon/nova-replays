# nova-replays

Сгенерированные пакеты «полного повтора» сетевых партий модпака Nova: карта, туман войны,
юниты по ходам, города, войны. Их читает страница повтора сайта
(https://coddysmon.github.io/TournamentModPack/).

**Руками здесь ничего не правится.** Содержимое перезаписывает конвейер на служебном сервере
одним коммитом (`push --force`), история не хранится.

- `f/index.json` — список партий, у которых есть повтор с юнитами
  (`{schema:"nova-full-replay-index", v, generated, matches:[{key, file, steps, players, ...}]}`);
- `f/<ключ партии>.json.gz` — пакет одной партии (gzip; формат `nova-full-replay`:
  начальное состояние `s0` и дельты `d` по шагам).

Что публикуется: только засчитанные сетевые партии (как на странице «Статистика»), только после
их окончания. Ники — как в рейтинге. Номера Steam не публикуются. Из чата — только реплики «всем»;
личные и командные вырезаются ещё при сборке.

Nova full replays (generated). Do not edit: overwritten by an automated export.
