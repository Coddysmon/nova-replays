# Повторы партий Nova

На [странице повторов с юнитами](https://coddysmon.github.io/TournamentModPack/replay-full.html) можно просматривать карту по ходам, следить за передвижениями юнитов, развитием городов и войнами.

Здесь публикуются повторы завершённых сетевых партий Nova, зачтённых в статистику. В повторах видны игровые ники и сообщения в общий чат. Личные и командные сообщения в повторы не входят.

- `f/index.json` — список доступных повторов.
- `f/` — файлы повторов.

[Статистика партий](https://coddysmon.github.io/TournamentModPack/stats.html) · [О моде и установка](https://coddysmon.github.io/TournamentModPack/)
